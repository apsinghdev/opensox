a 5 sec experiment.

let's say i have to learn redis

mainly there're two ways to do it.

by searching on google — "redis tutorial"

by searching on youtube — "redis tutorial"

i searched and here's what ive found:

![Redis tutorial on TutorialsPoint](/assets/blog/redis-tutorial.png)

now notice the technical jargons in it.

ive counted (chatgpt'd tbh) for you. total 15.

- Redis
- Open source
- BSD licensed
- Key-value store
- Data structure server
- Keys
- Strings
- Hashes
- Lists
- Sets
- Sorted sets
- C
- Deploy
- Scalable
- Performance-oriented

now if you're not an llm yourself already, you'll be like what is open source, what is BSD, what is key-value store?

and if you search again, 15 technical jargons on the way again.

habibi! welcome to the tutorial hell.

in this approach there are many problems:

- you're starting from "solution" and then seeing what's the problem.
- your brain never holds technical jargons for very long
- you never understand the core reason for a concept or a problem so you're never able to learn or solve the problem.
- this way you'll always fall back to the same loop of mediocre learning.

now take a look at this approach of learning the same concept.

![Redis notes from first principles](/assets/blog/redis-notes.png)

noticed a difference?

in this approach i didn't fall for technical jargons.

i asked a question as a 5 yo non-ipad kid would do.

and to avoid getting the jargon-heavy technical porn, i used [this](https://github.com/apsinghdev/orgasm-prompts/blob/main/ivc/prompts.md#refined-version) prompt to configure the gpt to use first principles.

you can read the prompt. it'll make it clearer.

in my definition, the core of first principles thinking is this:

1. pick a topic or problem
2. write it down in a doc
3. now stare at the topic or problem statement
4. force your intuition to come up with questions.
5. most important: block all the distractions — msgs, notifications, etc
6. write down the questions your intuition comes up with
7. and don't judge ur questions
8. sit down like this for 30 mins and you'll be in a flow
9. this flow is worth more than gold
10. now keep on asking questions recursively as ur intuition comes up with those
11. use chatGPT (or your fav ai) configured to use first principles to give you answers of these questions.

the beauty of this method is that it's universal.

you can apply this to learning a new technology, solving a tech problem, solving a non-tech problem, building hardware, building projects, and even solving a personal problem.

personally, this is the best thing ive learnt so far. i owe a lot to it.

when you know first principles, you're an individual thinker.

you rely on your mind and intuition and you use every other resource as a tool or source not something you're totally dependent upon.
